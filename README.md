# 医药行业财务看板

医药行业上市公司的财务看板：头部药企（美国、欧洲）、RNA、细胞疗法、罕见病与基因疗法、中国创新药，以及医疗器械、供应链（CXO、工具、耗材）、计算与 AI。全站中英对照，方便对照英文财报阅读。

- **网址**：https://youthme2026-6666.github.io/pharma-dashboard/
- **数据**：只来自各公司的官方文件。美股公司来自 SEC（10-Q、10-K、8-K），港股来自港交所披露易，A 股来自巨潮资讯；礼来 2026Q3 及以前的细分产品和地区明细来自礼来投资者关系网站的财务数据表。
- **维护**：每天由 GitHub Actions 自动运行：逐家公司检查新报告、解析、逐项核对，通过才写入；GPT 负责新增公司、读 PDF 报告、找重大事件这类需要判断的事，它的每条输出都要通过代码里的核对。某家公司出问题只影响它自己，并自动开 issue。

## 目录

| 路径 | 内容 |
|---|---|
| `companies/` | 公司清单 `registry.json`、待加清单 `watchlist.md` |
| `data/<公司>/` | 每家公司的统一格式数据（利润表、资产负债表、现金流量表、收入构成、重大事件）；礼来另有 7 份细数据 |
| `state/` | 每家公司的运行状态、每月 GPT 花费 |
| `page/` | 礼来细页面（结构、计算、绘图） |
| `agent/core/` | 多公司框架：公司循环、统一格式、报告、网站 |
| `agent/adapters/` | 各数据来源的适配器 |
| `agent/pipeline/` | 礼来细数据流程 |
| `agent/glossary.json` | 中英术语表 |
| `agent/SPEC.md` | 完整说明书（每一部分做什么、数据怎么来、怎么核对） |
| `agent/README.md` | 上线与运行说明 |
| `AGENTS.md` | 给编程助手的改代码规则 |

## 口径提醒

- 金额为各公司报告币种，单位百万；首页和公司页用“亿”展示（1 亿 = 100 百万）。
- 横向比较按报告期末日期对齐；财年不是自然年的公司（美敦力、Veeva 等）按各自财年标注。
- 礼来：2023 年的分产品收入原表以美元计，抽取时已换算成百万美元；早年的 Diabetes 统一改称 Cardiometabolic Health；没有减值费用的季度补 0（经营业利润勾稽验证）。
