# 想加的公司

在下面“待加”列表里每行写一家公司，写名字或代码都可以（中文名、英文名、股票代码都行），然后提交到仓库。

每天的自动运行会让 GPT 查清这家公司的身份、上市地、代码、分类、财年和币种，再用 SEC、港交所、巨潮的官方清单逐项核对；核对通过就写进 `companies/registry.json`，从下一次运行开始自动补历史数据、上线页面，并把这一行移到“已处理”。核对不过的会留在这里，并在运行报告里写明原因。

也可以在 GitHub 上开一个 issue，标题写公司名，加上 `add-company` 标签，效果一样。
